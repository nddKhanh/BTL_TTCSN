# Demo và nghiệm thu

1. Chạy `docker compose up --build` sau khi build backend.
2. Mở `frontend/index.html` qua static server.
3. Kiểm tra danh mục, lọc sản phẩm, chọn size/topping và thêm vào giỏ.
4. Tạo đơn; xác minh phí giao hàng và coupon được tính lại ở backend.
5. Đăng nhập tài khoản admin; kiểm tra dashboard, đơn hàng và sản phẩm.

Kiểm tra tự động: `backend/mvnw.cmd test`. Kiểm tra định dạng thay đổi: `git diff --check`.
