## Cách dùng

1. Chọn đúng một phương án 3 hoặc 5 thành viên.
2. Điền username thật sau khi từng người đã vào repository.
3. Tạo issue từ template và nhận một work package chưa có người làm.
4. Làm theo Git workflow; không vượt 3 file/commit hoặc 19 file/PR.
5. Cập nhật bảng theo dõi và lịch sử khi PR merge.
